h1. How to read this
One card per system: the branch of GVLMain to open, the settings, commands and status nodes in one table, and a short sequence to start and verify the system. Each system is one branch: Pen (with LIC01, OIC01 and the inlet supervisor), Inlet\[i\] (with its pump and the station's remote I/O), OxySystem\[i\] (with its pump and valve), Outlet and CommonRIO. Paths are relative to GVLMain and checked against the PLC program; \[i\] is 0\-based (Inlet\[0\] = inlet 1). Every node's type and behaviour: page 'CAS OPC UA interface'.
h2. Commands
|| Kind || How ||
| *Pulse* | Write TRUE; the PLC clears it. All Manual / Auto, {{Pen.Command.Start}} / Stop / OxygenStart / OxygenStop, {{Inlet\[i\].InletPump.Command.Reset}} (cleared when the pump state changes), calibrations, {{Outlet.Command.FaultReset}}. |
| *Held* | Write TRUE; the PLC holds it until the state confirms, then clears it: InletPump, OxyPump and HydraulicPump Start / Stop (in manual). |
| *Edge* | Write TRUE, then FALSE yourself: {{OxySystem\[i\].OxyPump.Command.Reset}}, every AlarmAck bit. |
| *Value* | Setpoints and modes: write the value, it stays (Setpoint, ManualOutput, ManualPosition, Mode). The controller setpoints are kept over a restart. |
| *Setting* | Config members: retained over a restart (GVLRetain). Change only during commissioning. |
