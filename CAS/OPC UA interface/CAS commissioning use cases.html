CAS (Heimdall): commissioning use cases

Generated 2026-11-04, nodes checked against scaleaq/heimdall-plc f3b20bb 2026-11-04.

Purpose

Use cases for field test and commissioning of the CAS (Heimdall) control system: for each, the OPC UA nodes to write and to read, in order, with the expected PLC response and the error scenarios. Structured after J. Cooling, Software Engineering for Real-Time Systems (2020), sec. 3.4.5: use case model (actors, use cases), text descriptions from START to FINISH, normal scenario, alternatives (errors handled in the interaction) and exceptions (the goal is abandoned), and include / extend relationships. Node paths are relative to GVLMain (the only node structure exposed over OPC UA) and checked against the PLC program; indices are 0-based (Inlet[0] = inlet 1). Node details: page 'CAS OPC UA interface'. Command convention: pulses (Manual, Auto, Start/Stop of the pen, Reset of an inlet pump, calibrations) are written TRUE and cleared by the PLC; InletPump / OxyPump Start and Stop are held by the PLC until the state confirms them; OxyPump Reset and AlarmAck bits are edges the client sets TRUE and then FALSE itself; setpoints are levels.

UC-00 Connect to the PLC

GoalLevelActorsIncludesExtends
An OPC UA session to the PLC with GVLMain found and a monitoring list running.subfunction (included by all)Commissioning engineer, SiteControl--

Preconditions

  • PLC powered, application running (CODESYS: RUN).
  • Client has its own PLC user account (anonymous access is off, register GEN-11).

START: The engineer starts the OPC UA client and connects to opc.tcp://<PLC IP>:4840.

Normal scenario

StepWhoAction, nodes, expected response
1ClientLogs in with its user (SecurityPolicy None today: password unencrypted, test network only).
2ClientBrowses once for GVLMain (node id ns=4;s=|var|<device>.Application.GVLMain); derives all other paths from it.
3ClientCreates one subscription (>= 1 s, queue size 1) with the monitoring list of the use case at hand; always includes Pen.Status.State, Pen.Status.Ready, Pen.Status.CommandRejected.
4ClientWrites FALSE to every command bit it may have left TRUE in an earlier session.

Alternatives (errors handled in the interaction)

ConditionWhoAction
Node not foundClientLogs it once, shows it as 'not available', looks it up again after a download or every 10 min (client requirements CON-05).

Exceptions (goal abandoned)

ConditionWhoAction
Login refused (BadUserAccessDenied / BadIdentityTokenInvalid)EngineerChecks user, password and the user's symbol rights in CODESYS. FINISH (abandoned).

FINISH: Session up, GVLMain found, monitoring list running.

UC-01 Configure and verify field communication

GoalLevelActorsIncludesExtends
Every remote I/O, oxy pump drive and Framo controller connected, with fresh data.user goalCommissioning engineer, Remote I/O and drives, Framo pump controller (PCC 1..3)UC-00-

Preconditions

  • Network installed; IP plan known (register IN-25).
  • Devices powered.

START: The engineer opens the communication settings.

Normal scenario

StepWhoAction, nodes, expected response
1EngineerWrites the CommonRIO address: CommonRIOConfig.IP, CommonRIOConfig.Port (502), then CommonRIOConfig.Enabled := TRUE.
2EngineerFor each inlet station i (0..2): InletRIOConfig[i].IP, InletRIOConfig[i].Port, InletRIOConfig[i].Enabled := TRUE.
3EngineerFor each oxy pump drive: InletRIOConfig[i].DriveIP, InletRIOConfig[i].DrivePort, InletRIOConfig[i].DriveUnitId, then InletRIOConfig[i].DriveEnabled := TRUE.
4EngineerFor each Framo controller: InletConfig[i].FramoIP, InletConfig[i].FramoPort, InletConfig[i].FramoUpdateRate.
5PLCConnects. Settings are retained (survive a restart); a changed IP or port makes the master reconnect.
6EngineerVerifies: drive OxySystem[i].OxyPump.Status.CommunicationOK TRUE; Framo Inlet[i].InletPump.Status.FramoConnected and Inlet[i].InletPump.Status.CommunicationOK TRUE, Inlet[i].InletPump.Status.FramoEndpoint shows the address in use.
7EngineerVerifies the RIO links indirectly: the station's sensors leave bad quality, e.g. Inlet[i].Input.LevelInsidePen.Status.BadQuality FALSE; CommonRIO: OxySystem[i].Input.OxygenFlow.Status.BadQuality FALSE.

Alternatives (errors handled in the interaction)

ConditionWhoAction
A drive reports a communication-loss fault after connecting (LFT 150 EtHF)PLCResets it automatically once per link recovery (OxySystem[i].OxyPump.Status.AutoResets counts up). Other faults: UC-06 step 'reset drive'.
Framo link up but heartbeat not answeredPLCInlet[i].InletPump.Alarm.HeartbeatTimeout raised, pump shown Unavailable. Engineer checks the PCC with Framo (IN-02).

Exceptions (goal abandoned)

ConditionWhoAction
Device not reachableEngineerChecks cabling, IP and port. FINISH (abandoned) for that device.

FINISH: All devices connected; no communication alarm.

UC-03 Commission the outlet dampers

GoalLevelActorsIncludesExtends
All four cylinders calibrated, moving in both directions, and the outlet following the operation mode.user goalCommissioning engineer, Supplier techniciansUC-00, UC-01-

Preconditions

  • Hydraulic unit filled and checked by Servi / Østerbø.
  • Emergency stop released.
  • Cylinder pressure transmitters and flow counters verified (UC-02).

START: The engineer puts the hydraulic pump in manual.

Normal scenario

StepWhoAction, nodes, expected response
1EngineerHydraulic pump: pulse Outlet.HydraulicPump.Command.Manual, check Outlet.HydraulicPump.Status.Available, pulse Outlet.HydraulicPump.Command.Start, check Outlet.HydraulicPump.Status.Running; pulse Outlet.HydraulicPump.Command.Stop; then Outlet.HydraulicPump.Command.Auto (in auto it runs on cylinder demand).
2EngineerPer cylinder i (0..3): pulse Outlet.Cylinder[i].Command.Manual; jog closed with Outlet.Cylinder[i].Command.Close held TRUE until the closed end, then FALSE.
3EngineerAt the closed end: pulse Outlet.Cylinder[i].Command.CalibrateClosed; wait until Outlet.Cylinder[i].Status.CounterSetRequest is FALSE and Outlet.Cylinder[i].Status.Calibrated TRUE.
4EngineerJog open with Outlet.Cylinder[i].Command.Open held TRUE until Outlet.Cylinder[i].Status.CurrentState = Opened (pressure-confirmed end), then FALSE; pulse Outlet.Cylinder[i].Command.CalibrateOpen.
5EngineerTests positioning: Outlet.Cylinder[i].Command.ManualSetpoint := 50, checks Outlet.Cylinder[i].Status.Position; then pulse Outlet.Cylinder[i].Command.Auto.
6EngineerOutlet as a whole: sets the openings per mode Outlet.Config.ModePosition (register OUT-10), selects Outlet.Command.Mode (0 O-35, 1 O-45, 2 O-60, 3 S-75), pulse Outlet.Command.Auto; checks Outlet.Status.Setpoint, Outlet.Status.Position, Outlet.Status.Mode.

Alternatives (errors handled in the interaction)

ConditionWhoAction
Emergency stop was pressedEngineerReleases it, pulse Outlet.Command.FaultReset, checks Outlet.Status.EmergencyStop FALSE.
Hydraulic pump feedback faultEngineerPulse Outlet.HydraulicPump.Command.Reset.
Counter set not confirmed (Outlet.Cylinder[i].Status.CounterSetFailed)EngineerAcknowledge Outlet.Cylinder[i].AlarmAck.FlowSensorFault (TRUE then FALSE), repeat CalibrateClosed.

Exceptions (goal abandoned)

ConditionWhoAction
Cylinder moves the wrong way or travel timeoutEngineerStops (release jog), checks valves and wiring with Servi. FINISH (abandoned).

FINISH: Cylinders calibrated and in auto; outlet follows the mode.

UC-04 Commission an inlet pump in manual

GoalLevelActorsIncludesExtends
Inlet pump i starts, runs at the speed set from the PLC, and stops, under PLC control.user goalCommissioning engineer, Framo pump controller (PCC 1..3), Supplier techniciansUC-00, UC-01-

Preconditions

  • Framo has commissioned the pump locally; PCC in remote.
  • Outlet open (UC-03) so the pen is not overfilled.
  • Framo link up (UC-01).

START: The engineer selects inlet pump i.

Normal scenario

StepWhoAction, nodes, expected response
1EngineerChecks the supervision times: InletConfig[i].StartupTime, InletConfig[i].ShutdownTime, InletConfig[i].SpeedDeviationLimit, InletConfig[i].SpeedDeviationDelay.
2EngineerPulse Inlet[i].InletPump.Command.Manual; checks Inlet[i].InletPump.Status.Manual TRUE.
3EngineerWrites the speed Inlet[i].InletPump.Command.Setpoint (rpm, 40..130).
4EngineerWrites Inlet[i].InletPump.Command.Start := TRUE (the PLC clears it once the pump starts).
5PLC/FramoInlet[i].InletPump.State goes Available (0) -> Starting (1) -> Remote (2); Inlet[i].InletPump.Status.ActualSpeed follows the setpoint in Remote.
6EngineerChanges the setpoint in steps; checks speed and Inlet[i].InletPump.Input.MotorCurrent, Inlet[i].InletPump.Input.MotorPower.
7EngineerWrites Inlet[i].InletPump.Command.Stop := TRUE; State -> Stopping (3) -> Available (0) (the PLC clears Stop).
8EngineerPulse Inlet[i].InletPump.Command.Auto (or leaves it in manual until UC-05).

Alternatives (errors handled in the interaction)

ConditionWhoAction
Pump in Hold (4) or Lockdown (5)EngineerFixes the cause with Framo, pulse Inlet[i].InletPump.Command.Reset; the PLC holds the reset until the state changes, else Inlet[i].InletPump.Alarm.FailedToReset.
Pump does not start within StartupTimePLCInlet[i].InletPump.Alarm.StartUpTimeout.

Exceptions (goal abandoned)

ConditionWhoAction
Unavailable (9): link or PCC not readyEngineerBack to UC-01. FINISH (abandoned).

FINISH: Pump verified in manual; left in auto or manual as planned.

UC-05 Start the pen and commission level control

GoalLevelActorsIncludesExtends
The pen running with the inlet pumps in auto and LIC01 holding the over-height at the setpoint.user goalCommissioning engineer, Operator, Framo pump controller (PCC 1..3)UC-00, UC-02-

Preconditions

  • UC-03 and UC-04 finished for the pumps in service.
  • Outlet in auto at the chosen mode.

START: The engineer prepares the pumps for automatic operation.

Normal scenario

StepWhoAction, nodes, expected response
1EngineerPer pump in service: InletConfig[i].InletPumpEnable := TRUE and pulse Inlet[i].InletPump.Command.Auto.
2EngineerSets Pen.Command.LevelSetpoint (m over-height, e.g. 0.06) and checks LIC01 tuning PenConfig.LevelController.Kp, PenConfig.LevelController.Ti, PenConfig.LevelController.MinOutput, PenConfig.LevelController.MaxOutput.
3EngineerChecks the pump count settings PenConfig.PumpTargetSpeed, PenConfig.PumpAddSpeed, PenConfig.PumpRemoveDelay, PenConfig.PumpAddDelay, PenConfig.PumpCycleTime.
4EngineerWaits for Pen.Status.Ready TRUE (a pump in auto is Available AND a valid level pair).
5EngineerPulse Pen.Command.Start.
6PLCPen.Status.State Stopped (0) -> Starting (1): all candidate pumps start, LIC01 tracks their speed; -> Running (2) when a pump is in Remote; LIC01 to auto, bumpless.
7EngineerMonitors Pen.Status.OverHeight against Pen.Command.LevelSetpoint, LevelController.Output.OUT (total rpm), PenInletSupervisor.AutoSpeedSetpoint (rpm per pump), PenInletSupervisor.PumpsWanted.
8EngineerTests LIC01 manual: pulse LevelController.Command.Manual, write LevelController.Command.ManualOutput (rpm per pump), then pulse LevelController.Command.Auto (the PLC sets the setpoint to the current level, bumpless).

Exceptions (goal abandoned)

ConditionWhoAction

UC-08 Check and acknowledge alarms

GoalLevelActorsIncludesExtends
Every alarm raised during a test is seen, understood and acknowledged.subfunction (extends UC-01 to UC-07)Commissioning engineer, Operator, SiteControlUC-00UC-01 .. UC-07

Preconditions

  • Session up (UC-00).

START: An alarm changes state.

Normal scenario

StepWhoAction, nodes, expected response
1ClientReads the alarm byte, e.g. Inlet[i].InletPump.Alarm.StartUpTimeout (AlarmState: 0 Normal, 1 Unacknowledged, 2 Acknowledged, 3 RetainUnacknowledged, 4 Suppressed).
2EngineerFinds and fixes the cause.
3EngineerAcknowledges with a rising edge on the matching ack bit, e.g. Inlet[i].InletPump.AlarmAck.StartUpTimeout TRUE, then FALSE (the PLC never clears ack bits).
4PLC1 -> 2 while the condition is present, -> 0 once it is gone.

Alternatives (errors handled in the interaction)

ConditionWhoAction
Oxy pump drive faultEngineerAck does not reset the drive: OxySystem[i].OxyPump.Command.Reset (UC-06).
Hydraulic pump feedback faultEngineerNeeds Outlet.HydraulicPump.Command.Reset, not an ack.

FINISH: No unacknowledged alarm; causes recorded.

UC-09 Fault tests

GoalLevelActorsIncludesExtends
The planned failures give the designed reaction.user goal (extends UC-05 to UC-07)Commissioning engineer, Supplier techniciansUC-00, UC-08UC-05 .. UC-07

Preconditions

  • Pen Running with oxygenation (UC-05..07).
  • Test plan agreed (who pulls which cable, when).

START: The engineer announces the test.

Normal scenario

StepWhoAction, nodes, expected response
1EngineerFramo link of one pump down: expects Inlet[i].InletPump.Alarm.HeartbeatTimeout, Inlet[i].InletPump.Status.CommunicationOK FALSE, oxygen line i stops (Inlet[i].InletPump.Status.OxyPermit FALSE), the other pumps take over in LIC01. Note the Framo behaviour on heartbeat loss (IN-41).
2EngineerInlet RIO link down: expects the station's level pair invalid (Inlet[i].Input.LevelInsidePen.Status.BadQuality) and LIC01 continuing on the other pairs.
3EngineerOxy pump drive link down: expects OxySystem[i].OxyPump.Status.CommunicationOK FALSE, line stops; on return the comm-loss fault is reset automatically.
4EngineerInlet pump trip (Framo): expects Lockdown, the others take its share; Reset after the fix (UC-04 alternative).
5EngineerEmergency stop: expects the designed stop of pumps and oxygen (open: IN-14, IN-28, OX-21).
6EngineerRecords results; deviations go into the register.

Exceptions (goal abandoned)

ConditionWhoAction
Unexpected reaction that endangers the fishEngineerStops the test, restores normal operation. FINISH (abandoned).

FINISH: All tests done and recorded.
